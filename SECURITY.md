# Security Policy

## Supported versions

Only the latest code on `main` is currently supported. Latte is an early
0.0.1 release and should not be used for sensitive content or credentials.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting form](https://github.com/azusachino/latte/security/advisories/new)
and include reproduction steps, affected versions, and an impact assessment.

Do not include secrets or private user data in a report. We will acknowledge
reports when practical and coordinate a fix or mitigation through the private
advisory.
